This site is built with **Blueprint Theme** — a technical drawing–inspired Jekyll theme for engineers, developers, and technical writers.

## DESIGN LANGUAGE

The Blueprint aesthetic draws from actual engineering drawings:

- **Grid background** — real ISO technical drawing grid (fine + major grid lines)
- **Corner tick marks** — every card and block has engineering-style fold marks
- **Annotation orange** — callouts, notes, and section markers use orange-red (drafting pencil color)
- **Monospace titles** — Share Tech Mono gives headings a plotted-text feel
- **Revision block** — the footer mimics a technical drawing title block

## CONFIGURATION

```yaml
blueprint:
  grid: "fine"           # fine | coarse | none
  fold_marks: true       # engineering corner marks
  revision_block: true   # title block in footer
  line_weight: "normal"  # light | normal | heavy
```
